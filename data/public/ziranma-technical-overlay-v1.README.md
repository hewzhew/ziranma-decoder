# Ziranma technical overlay v1

This small input-method, linguistics, electronics and hardware vocabulary is
manually curated for the Ziranma TSF Alpha. It is original project data
distributed under the same MPL-2.0 license as the surrounding source code; it
is not copied from a third-party dictionary.

The numbers in the `frequency` column are deterministic relative ordering
weights, not corpus measurements. The Alpha consults this overlay only for an
exact, complete Ziranma code and deduplicates it against the pinned public Rime
candidate snapshot.

Entries are selected manually from terms used by this project. Public
dictionaries may be consulted to confirm that a term and reading are in
established use; their raw rows and weights are not copied into this overlay.

The overlay remains embedded in the local development DLL until the immutable
candidate-package format can represent and verify multiple sources with
separate provenance.
