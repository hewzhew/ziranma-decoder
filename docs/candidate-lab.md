# 候选实验台：从程序指标到真实手感

## 目的

候选实验台是公开解码器与未来输入界面之间的最小桥梁。它接受一串连续、
无词界的自然码按键，展示当前主候选和独立的锚定尾简颠倒恢复候选，同时
保留分词、简拼、纠错、未解析输入与语言分证据。

它不监听键盘、不读取持续记录、不学习本次输入，也不自动上屏：

```powershell
cargo run --release -- candidate-lab mafmkm 3
cargo run --release -- candidate-lab mafkmm 3
```

Top-K 必须在 1～10。按键串必须是非空的小写英文字母。

## 两个候选栏

- **主候选**沿用当前连续句解码器的保守排序。它仍可能包含自由混合简拼，
  因而是研究参照，不是已经批准的产品默认协议。
- **颠倒恢复栏**只额外暴露“每词首音节完整、尾部简写”的一次相邻按键
  颠倒，而且排除主栏已经出现的相同文本。未来界面必须显式进入这一栏，
  不能暗中把它混进普通首选。

实验台不会为同一输入生成一个不存在的“正确答案”。正确候选是否出现、
是否容易找到，仍由宝宝实际试用或事先冻结的课程目标判断。

## 动作投影

每个可见候选使用同一套最小口径：

```text
投影动作 = 已按字母 + 1 次候选选择 + 显式切栏动作
完整码基线 = 该候选各词规范完整码字母 + 1 次候选选择
净省动作 = 完整码基线 - 投影动作
```

主栏切栏动作为 0，颠倒恢复栏为 1。选择第 1 或第 10 个候选在这一版都只
计一次选择；这不是在宣称视觉查找、翻页和不同数字键没有成本，而是刻意
不伪造尚未测量的界面行为。含未解析片段的候选没有完整码基线，报告会
明确留空。

## 第一份可复现实例

固定公开词典下：

- `mafmkm` 的主栏第 1 是“麻烦猫猫”：6 个字母 + 1 次选择，相对 8 个
  完整码字母 + 1 次选择，投影净省 2；
- `mafkmm` 把 `mkm` 的前两键打反，“麻烦猫猫”进入独立恢复栏第 1：
  6 个字母 + 1 次选择 + 1 次切栏，投影净省 1。

这些结果证明报告链路能够区分正常尾简与一次颠倒，不证明公开词频已经
覆盖宝宝的真实表达，也不证明动作投影等于真实手感。

## 下一步与停止条件

下一层可以增加事先冻结的 `--expect` 课程目标，报告目标在两个栏中的
名次；再下一层才是本地候选窗或键盘交互。只有以下条件同时成立，动作
投影才能升级为体验结论：

- 真实候选选择、翻页和切栏动作能够被可靠记录；
- 完整码基线没有退化；
- 省下的字母没有被查找、切栏和改错抵消；
- 改善能在未参与设计的后续自然会话中复现。

若自由混合简拼持续挤占主栏、恢复栏引入的错误候选多于救回，或实际总
动作不降，就停止扩展相应分支，而不是继续调分掩盖。
