# 候选实验台：从程序指标到真实手感

## 目的

候选实验台是公开解码器与未来输入界面之间的最小桥梁。它接受一串连续、
无词界的自然码按键，默认只展示适合直接阅读的候选、预计操作与简拼说明。
研究证据和机器接口分属另外两个显式输出层。

它不监听键盘、不读取持续记录、不学习本次输入，也不自动上屏：

```powershell
cargo run --release -- candidate-lab mafmkm 3
cargo run --release -- candidate-lab mafmkm 3 --expect 麻烦猫猫
cargo run --release -- candidate-lab mafkmm 3 --recovery --expect 麻烦猫猫
cargo run --release -- candidate-lab mafmkm 3 --verbose
cargo run --release -- candidate-lab mafmkm 3 --json
```

每栏显示数必须在 1～10。按键串必须是非空的小写英文字母。

## 三层输出

- **默认层**使用简洁中文，只保留候选文字、预计操作、与完整输入相比
  多或少几次，以及每个片段的简拼/纠错摘要。
- **详细层**由 `--verbose` 显式开启，展示候选评分、完整动作拆分、纠错
  预算，以及带中文解释的 `unigram` / `bigram` 语言模型证据。
- **机器层**由 `--json` 显式开启，使用
  `ziranma-candidate-lab-v1` 模式和稳定英文字段名。成功输出不夹带
  人类提示文字，可以直接交给 JSON 解析器。

`--verbose` 与 `--json` 不能同时使用。命令名、选项名、模式版本和 JSON
字段保留英文；候选解释、操作提示与错误信息使用中文。

## 课程式目标检查

`--expect <文字>` 事先冻结一个目标，并报告它在本次可见候选中的精确
名次。例如：

```powershell
cargo run --release -- candidate-lab mafmkm 3 --expect 麻烦猫猫
cargo run --release -- candidate-lab mafkmm 3 --recovery --expect 麻烦猫猫
```

第一条会报告目标位于普通候选第 1 名、按键颠倒栏未检查；第二条会报告
普通候选前 3 项未找到、目标位于按键颠倒候选第 1 名。

检查只比较完全相同的目标文字，不推断同义表达；“前 3 项未找到”也只
描述已经请求的可见深度，不等于整个候选空间不存在。`--json` 会输出
`match: "exact_text"`、两个栏的名次和 `recovery_checked`，从而保留
“未命中”与“根本未检查”的区别。目标只来自本次命令参数，不会保存或
用于学习。

## 两个候选栏

- **普通候选**沿用当前连续句解码器的保守排序。它仍可能包含自由混合简拼，
  因而是研究参照，不是已经批准的产品默认协议。
- **颠倒恢复栏**只额外暴露“每词首音节完整、尾部简写”的一次相邻按键
  颠倒，而且排除普通栏已经出现的相同文本。它默认完全隐藏，只有加入
  `--recovery` 才输出；未来界面也必须显式进入这一栏，不能暗中把它
  混进普通首选。

实验台不会为同一输入生成一个不存在的“正确答案”。正确候选是否出现、
是否容易找到，仍由宝宝实际试用或事先冻结的课程目标判断。

## 动作投影

每个实际输出的候选使用同一套最小口径：

```text
投影动作 = 已按字母 + 1 次候选选择 + 显式切栏动作
完整码基线 = 该候选各词规范完整码字母 + 1 次候选选择
净省动作 = 完整码基线 - 投影动作
```

普通栏切栏动作为 0，颠倒恢复栏为 1。选择第 1 或第 10 个候选在这一版都只
计一次选择；这不是在宣称视觉查找、翻页和不同数字键没有成本，而是刻意
不伪造尚未测量的界面行为。含未解析片段的候选没有完整码基线，报告会
明确留空。

## 第一份可复现实例

固定公开词典下：

- `mafmkm` 的普通栏第 1 是“麻烦猫猫”：6 个字母 + 1 次选择，相对 8 个
  完整码字母 + 1 次选择，投影净省 2；
- `mafkmm --recovery` 把 `mkm` 的前两键打反，“麻烦猫猫”进入独立
  恢复栏第 1：
  6 个字母 + 1 次选择 + 1 次切栏，投影净省 1。

这些结果证明报告链路能够区分正常尾简与一次颠倒，不证明公开词频已经
覆盖宝宝的真实表达，也不证明动作投影等于真实手感。

## 下一步与停止条件

下一层可以把多条事先冻结的 `--expect` 课程整理成独立公开用例；再下一层
才是本地候选窗或键盘交互。只有以下条件同时成立，动作投影才能升级为
体验结论：

- 真实候选选择、翻页和切栏动作能够被可靠记录；
- 完整码基线没有退化；
- 省下的字母没有被查找、切栏和改错抵消；
- 改善能在未参与设计的后续自然会话中复现。

若自由混合简拼持续挤占主栏、恢复栏引入的错误候选多于救回，或实际总
动作不降，就停止扩展相应分支，而不是继续调分掩盖。
