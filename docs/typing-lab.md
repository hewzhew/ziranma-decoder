# 端到端连续输入实验台

## 目的

`typing-lab` 把仓库已有的连续句子解码和 Tab 单字笔画过滤接到同一个最小
交互循环中。它用于回答“实际逐键输入时能不能顺畅完成一次选择”，而不是
继续用静态报告代替手感，也不是 Windows TSF 输入法。

```powershell
cargo run --release -- typing-lab
```

Windows 交互终端会直接读取每次按键，不需要 Enter。支持 ANSI alternate
screen 的终端使用独立画面，逐键刷新不会铺满主滚动记录。界面只保留已经
选中的文字、当前双拼串、可见候选和此刻可用的控制键。

## 普通输入

- `a`～`z`：追加到同一个无词界双拼串；`q`、`t` 等字母没有退出含义；
- `Backspace`：删除最后一个双拼字母；
- `Space` 或 `Enter`：选择第一项；
- `1`～`9`、`0`：选择第 1～10 项；
- `-`：向前翻页；
- `+` 或 `=`：向后翻页；
- `PageUp` / `PageDown`：备用翻页键；
- `Esc`：有输入时清空；空输入时退出。

候选直接来自现有 `Decoder::decode_sentence`，因此复用相同的自动词界、
简拼解释、全局一次纠错预算和保守排序。实验台不复制或修改解码算法。

逐键输入时只计算当前页需要的候选。第一次向后翻页才把相同按键串按需
展开到最多 200 项；停留在同一按键串继续翻页时复用该结果，不重复解码。
这条深池只用于让公开排序较深的候选仍可被显式选择，不会混入首屏排序。

普通候选被显式选择后，实验台在内存中记住“当前按键串 → 该候选”。本次
运行中再次输入完全相同的按键串时，该候选置顶，即使它不在浅层候选池中；
退出程序后记忆立即消失。它不从一次选择推断别的词或相似按键，也不是
`--personal-cache`、持久个人模型或准确率评测。

## Tab 单字辅助

当前双拼串必须恰好对应公开词典中的一个完整单字码，Tab 才能进入笔画
辅助。进入后：

- `h/s/p/n/z`：横、竖、撇、捺、折；
- `Backspace`：撤回一画，空前缀时返回普通候选；
- `Esc`：立即返回普通候选；
- 数字：选择当前过滤结果。

Tab 继续复用 `ShapeLab` 的冻结单字池和稳定过滤：只删除不匹配项，不改变
原相对顺序。多词连续输入不会被悄悄解释成单字找字请求。

## 重定向回退

stdin 或 stdout 不是交互终端时，每一行作为一个动作。普通小写字母始终是
输入，因此控制命令带冒号：`:tab`、`:esc`、`:quit`；空行选择第一项，
数字选择对应候选，`-` / `+`（或 `=`）翻页，`:back` 表示退格；也保留
`:prev` / `:next`。这种模式用于脚本验证，不模拟逐键延迟。

## 隐私与边界

实验台只读取仓库固定的公开 Rime 与 Conway 快照，不读取持续记录器、私人
胶囊或个人模型，也不写文件。它只在进程内记住本轮显式选择；输入、候选
和已选文字会显示在终端，PowerShell 重定向、录屏以及不支持独立画面的终端
滚动仍属于明文边界。

当前只累积本轮已选文字，不提供光标移动、标点、恢复栏切换、系统输入框
上屏或持久个人排序。深池翻页是可达性兜底，不是首屏排序解法。下一步依次
验证：

1. 本轮同码记忆能否稳定完成“找到一次，随后首选”的闭环；
2. 独立会话评测通过后，接入显式点名历史的内存个人候选；
3. 再实现加密个人排序 candidate 的持久化与提升/回退；
4. 之后加入独立的按键颠倒恢复入口和渐进课程。

每一层继续使用同一解码和选择接口，不另造第二套候选逻辑。
