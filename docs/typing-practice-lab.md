# 打字练习实验室

## 要解决的问题

日用输入里有些目标不是一次候选选择完成的。例如输入 `xmuufu` 后先得到“线束缚”，
再删除末尾“缚”留下“线束”。这既不是两个单字的相邻选择，也不能仅凭“删得很快”
认定为新词学习。

练习实验室应提供一个用户主动进入的真实编辑区，让候选提交、后续删除、继续输入和
最终保留结果处在同一个可定位事件流里。它的首要产物是可审阅证据，不是自动学习。

## 与现有工具的分工

- `typing-lab` 是固定公开词典的终端沙盒，适合重现候选、翻页和末尾裁剪；它不是
  Windows TSF 宿主，退出即清空。
- 输入法内 `xuy + Tab` 保存输入法自身的候选展示、选择和提交；宿主在上屏后的普通
  Backspace 不一定再进入输入法，因此它不能单独证明最终文档变化。
- Codex 持续记录器能观察点名的 Codex 输入框及后续文档差分，适合自然使用研究，
  但不应扩展成任意应用的全局监听器。
- 新练习实验室应是一个独立、可退出的原生 Windows 编辑宿主，只观察自己窗口内的
  练习文本；它不扫描其他应用，也不要求全局键盘钩子。

## 交互草案

1. 打开后先看到空白练习区和“开始本轮”；未开始时不记录。
2. 开始后使用任意已安装输入法正常打字。顶部只显示“正在记录本练习区”和事件数，
   不实时评价好坏。
3. 遇到值得说明的地方，可按“标一下这里”；程序只创建一个时间和事件范围标记，
   不打断输入，也不立即要求填写说明。
4. 结束后进入时间线：提交、删除、替换和取消按输入片段分组。程序可以提出
   “较长候选裁成短语”“删除后重新输入”“候选选择较深”等结构化观察。
5. 用户逐项选择“重要 / 普通 / 忽略”，并可补充“本来想输入什么”“哪里不舒服”。
   未确认的观察只保留为行为事实，不进入个人词典。
6. 保存时使用 Windows 当前用户 DPAPI 写入不可变加密分段；查看、标注和可恢复删除
   由独立管理界面完成。不会自动联网或自动发送。

## 证据优先级

归并使用结构证据，不使用单一速度门槛：

1. 同一练习编辑区中的字符范围和光标位置；
2. 提交插入范围与后续删除/替换范围是否重叠；
3. 事件是否直接相邻，中间是否发生光标移动、标点、焦点切换或其他编辑；
4. 按键是否完整，候选提交码与最终文字是否能按完整双拼严格对齐；
5. 毫秒间隔只用于显示和离线比较，不单独决定“正确”“错误”或“想学习”。

`CommitTailTrimDetector` 已实现其中的尾部裁剪观察。对于
`xmuufu → 线束缚 → 删除缚`，它会保留来源提交、删除范围、剩余“线束”和实际间隔；
仅在完整六键严格对应三个上屏字时，才附带 `xmuu → 线束` 的待审阅提案。提案不会
自动写入词典。

## 记录格式与边界

第一版复用现有严格事件胶囊和不可变加密分段，使用独立的
`typing-practice-v1` capture profile，避免与 Codex UIA 自然记录混淆。每条事件可含：

- 会话内相对毫秒、按键动作及完整性；
- 组合文字、提交文字与候选选择；
- 文档净变化、字符位置和位置证据；
- 用户标记绑定的事件范围与后补说明。

外层状态只显示会话时间、事件数、完整性和加密版本。原文、按键、候选、提案和说明
全部在 DPAPI 密文中。达到事件或字节上限时停止本轮并如实提示；不循环覆盖旧事件。

## 实施顺序

1. **已完成**：终端 `typing-lab` 可以从已选文字末尾退格；尾部裁剪观察器不依赖
   时间阈值，并能从严格完整码生成待审阅提案。
2. **已完成**：终端实验台用 F2 / `:mark` 建立有界的仅内存时间线；候选提交、
   末尾裁剪和现场标记分别保留模式、码、名次或页范围，退出时统一查看且不写文件。
3. **已完成第一阶段**：`typing-practice` 建立只观察自己标准 EDIT 控件的原生 Windows
   宿主。用户明确开始后，它以 UTF-16 位置记录有界插入、删除、替换与光标范围，
   支持练习区内 F2 原地标记以及按钮标记；结束后统一查看，退出即清空。事件结构有公开合成测试，
   但真实 TSF 组合、候选提交和普通 Backspace 仍需后续人工清单验证，不能凭窗口能打开
   就宣称宿主兼容。
   查看层只按可证明的位置连续性归并相邻插入、同向删除和同位置替换演变，原始事件仍
   保留在内存中；插入后再删除、标记前后或不同位置的编辑不会被归成一组，也不使用
   单一速度阈值猜测意图。
   结束后的审阅还会把“一个非空插入后，紧邻事件从同一范围连续裁去末尾并留下非空
   前缀”列为中性的结构观察；它显示实际保留与删除内容，但不把插入冒充候选提交，
   不因时间短就猜测意图，也不会自动学习。
   练习窗口离开前台时会另建一个不含外部应用名、窗口标题或路径的结构边界；切回后
   恰好相邻的编辑不会越过这个边界合并。
   它已进入独立用户工具包，可由 `typing-practice.cmd` 或桌面启动器固定动作
   `practice` 打开；用户工具刷新不构建或替换 TSF DLL。
4. 验证通过后，接入独立 `typing-practice-v1` 加密分段；仍保留明确开始/结束按钮，
   不把仅内存原型悄悄变成常驻记录器。
5. 在“猫猫应愿”中增加练习会话列表、结构化标注和逐项批准；在真实样本足够前，
   不把提案自动接入在线个人学习。
